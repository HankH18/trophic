# HAND-AUTHORED MAP for "cindershelf" — this file IS the map, not a collision spec for a painting.
#
# It started from tools/mapgen/layouts/cindershelf.txt (written by tools/mapgen/seed.ts) and keeps
# that file's header block and "---" separator. The grid below it was redrawn by hand: the town is
# now COMPOSED FROM TILES stamped cell by cell from this layout, so painting and collision
# correspond by construction and every building, lane and mass below is a deliberate placement.
# Re-running the seeder would OVERWRITE this; the composer and the renderers read this file.
#
# ── coordinate space ─────────────────────────────────────────────────────────
# space        map-native pixels, origin TOP-LEFT (data/nodes/*.json props[].x/y are in this space)
# grid         64 cols × 64 rows, one character per collision cell
# cell         16 native px  (balance.map.collisionCellPx; 1024/64 = 16)
# map          1024 × 1024 native px, rendered ×2 → 2048 world px
# tiles        64 × 64 movement tiles of 32 world px
# col ← x      col = floor(nativeX / 16);  a cell's centre is native (16·col + 8, 16·row + 8)
# centre       native (512, 512) = cell (32, 32) = the tile firstWalkableTile starts on
#
# ── seeded from ──────────────────────────────────────────────────────────────
# biome        Steppe
# adjacency    r3, r4
# bottom edge  r3  — ^ at (22,63), on r3's top mouth
# top edge     r4  — ^ at (31,0), on r4's haul road
# settlement   yes — building footprints are placed
# props        cindershelf-shrine-mine @ (372,508) → cell (23,31); cindershelf-shrine-deep @ (706,604) → cell (44,37)
#
# ── decisions this file made ─────────────────────────────────────────────────
# · THE PLACE. A mining town on black volcanic ash, split by one band of dark rock lying across
#   the ash above the middle, its ends stopping well short of both sides so the town is a loop
#   with one short way over the steps and two long ways round. Working half below (shaft head,
#   shrine, relic forge, ladder head, slag heap, gym forge); living half above.
# · THE 32-CELL DEAD-STRAIGHT THREE-ROW STREET IS GONE. It was the only thing in the set that
#   read as an axial planned street, with three buildings sitting on it at even spacing. The far-
#   ash lane now steps three times and the three segments share no row: the west street at rows
#   14-16, the middle two steps up at rows 10-12, the east street lowest at rows 17-19.
# · FIVE FOOTPRINTS, five sizes, all inside the shipped 85-140px band (two were outside it):
#     boarded company store (40,10)-(45,15)  6x6 door (42,16)  the smallest
#     supply shop          (22,2)-(29,7)     8x6 door (25,8)
#     gym forge            (37,49)-(43,55)   7x7 door (40,56)
#     inn                  (8,6)-(15,12)     8x7 door (11,13)
#     relic forge          (43,27)-(50,34)   8x8 door (47,35)  the largest
# · THE RIM IS TWO MATERIALS: "R" basalt shoulder and "#" clinker and slag bank. Every edge used
#   to be a uniform band of one character four to seven cells deep — a matte frame by another
#   name. It is now mixed on all four sides with a depth profile and four shoulders reaching in.
# · BOTH MOUTHS MOVED TO MEET THEIR NEIGHBOURS: bottom col 22 = r3's top mouth, top col 31 =
#   r4's haul road. Both seams used to snap about twenty columns sideways. r4's track is authored
#   as running almost straight, so this map's top mouth moved rather than r4's bottom one.
# · NO ENCOUNTER TERRAIN AT ALL, and no tree. "No grass anywhere over the whole picture" is the
#   clause of the subject line that must never be cut; nothing grows on the ash.
#
# ── legend (tools/mapgen/legend.ts) ──────────────────────────────────────────
#   .  floor  open-ground         plain walkable ground; the default fill
#   ,  floor  scrub               walkable but textured — long grass, ferns, heather
#   :  floor  path-corridor       the worn track that joins the map edges through the middle
#   o  floor  centre-clearing     the open region at native (512,512) the spawn search lands in
#   ~  floor  shallow             walkable water margin — wadeable, not a wall
#   #  WALL   wall                generic impassable mass with no more specific kind
#   B  WALL   building-footprint  a building the player walks around, never through
#   T  WALL   tree-mass           trunks and thicket dense enough to stop a walk
#   W  WALL   water               open water — deep enough to block
#   R  WALL   rock                basalt, scree, standing stone, crater rim
#   F  WALL   fence               a thin built barrier — pen rail, jetty edge, ore-cart rail
#   *  ANCH   prop-anchor         a data/nodes/*.json props[] entry, at floor(x/cellPx), floor(y/cellPx)
#   @  ANCH   spawn-anchor        documentary marker for the centre cell the spawn search starts from
#   ^  ANCH   edge-mouth          the cell where a corridor meets the map edge; one per declared adjacency
#   D  ANCH   door-anchor         the walkable cell a building is entered from
#
# On this map: "R" is cracked basalt — the frame, the band and the outcrops. "#" is the dark holes and
# the black slag heap. "F" is the ore-cart rail and the shaft/ladder timbering. "W" is the two stone
# bathing tubs and "~" their wet apron; there is no other water.
#
# Only "#"-class characters block. tools/mapgen/layout.ts normalises every WALL character to "#"
# before game/collision.ts gridFromAscii sees it; ANCH characters parse as floor and are read again
# on a second pass. Region kinds are open strings — add a row to the legend, not a case to a switch.
