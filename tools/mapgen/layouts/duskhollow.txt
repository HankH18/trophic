# HAND-AUTHORED MAP for "duskhollow". This grid IS the map: the tile composer stamps a tile per
# character, so every building, track, rock band and patch of heather below is where it will be
# on screen, and the collision mask and the painting are the same file by construction.
#
# Redrawn from the seeded starting layout, which was a collision spec and not a place. Re-running
# tools/mapgen/seed.ts would OVERWRITE this; the renderers read this file, not the seeder.
#
# ── coordinate space ─────────────────────────────────────────────────────────
# space        map-native pixels, origin TOP-LEFT (data/nodes/*.json props[].x/y are in this space)
# grid         64 cols × 64 rows, one character per collision cell
# cell         16 native px  (balance.map.collisionCellPx; 1024/64 = 16)
# map          1024 × 1024 native px, rendered ×2 → 2048 world px
# tiles        64 × 64 movement tiles of 32 world px
# col ← x      col = floor(nativeX / 16);  a cell's centre is native (16·col + 8, 16·row + 8)
# centre       native (512, 512) = cell (32, 32) = the tile firstWalkableTile starts on
#
# ── seeded from ──────────────────────────────────────────────────────────────
# biome        Vale
# adjacency    r4, r5
# bottom edge  r4  — ^ at (32,63), on r4's top mouth
# top edge     r5  — ^ at (26,0), on r5's bottom mouth
# settlement   yes — building footprints are placed
# props        duskhollow-sign-observatory @ (500,430) → cell (31,26), at the foot of the steps
#
# ── decisions this file made ─────────────────────────────────────
# · THIS MAP WAS REDRAWN, and had to be on contract grounds alone. It shipped with EIGHT walkable
#   edge corridors against a declared adjacency of two — the left and right edges open and four
#   separate runs on the bottom — because its heather and turf ran off three frames. The file's
#   own header claimed "left 0, right 0"; it had counted "^" characters, where the contract counts
#   walkable runs. Four of its five footprints were outside the 85-140px band, and two header
#   lines were blank, which broke the byte-identical round trip tests/unit/mapgen.test.ts asserts.
# · IT IS ALSO THE HALF OF THE cindershelf/duskhollow PAIR THAT MOVED, for the same reason
#   bowerdeep moved rather than brackwater: cindershelf's composition is pinned harder by its own
#   subject line, while duskhollow's line gives this map devices cindershelf cannot have.
# · WHAT SEPARATES IT: TWO rock bands with the track running between them, not one band the track
#   crosses; a gym hall whose footprint is INSIDE the lower band, so its door is a dark doorway
#   cut in rock and not a front wall on turf; a fork with two different KINDS of destination — a
#   stair that dead-ends at one building on a shelf, and a track that carries on round the band's
#   end and off the map; a shepherd's fold of dry-stone walling; a dry-stone head-dyke running in
#   off the moor's edge; iron lamp posts standing beside the track; heather at a tenth of the
#   walkable ground where cindershelf has none. And the moor is OPEN — a shallow rim and two clean
#   slabs, against cindershelf's enclosed basin full of clinker.
# · FIVE FOOTPRINTS, five sizes, all in band:
#     supply shop  (22,39)-(27,44)  6x6 door (24,45)  the smallest
#     lampwright   (41,31)-(46,37)  6x7 door (43,38)
#     gym hall     (38,44)-(45,49)  8x6 door (41,50)  set into the lower band
#     inn          (14,30)-(20,37)  7x8 door (17,38)
#     observatory  (16,8)-(23,15)   8x8 door (19,16)  the largest, alone on the shelf
# · THE PROP IS ON ITS AUTHORED CELL (31,26), at the foot of the pale stone steps just above the
#   middle, which is where its own feature string puts it. data/nodes/duskhollow.json is unchanged.
# · THE MOUTHS SIT ON THEIR NEIGHBOURS: bottom col 32 = r4's top mouth, top col 26 = r5's bottom.
#
# ── legend (tools/mapgen/legend.ts) ──────────────────────────────────────────
#   .  floor  open-ground         plain walkable ground; the default fill
#   ,  floor  scrub               walkable but textured — long grass, ferns, heather
#   :  floor  path-corridor       the worn track that joins the map edges through the middle
#   o  floor  centre-clearing     the open region at native (512,512) the spawn search lands in
#   ~  floor  shallow             walkable water margin — wadeable, not a wall
#   #  WALL   wall                generic impassable mass with no more specific kind
#   B  WALL   building-footprint  a building the player walks around, never through
#   T  WALL   tree-mass           trunks and thicket dense enough to stop a walk
#   W  WALL   water               open water — deep enough to block
#   R  WALL   rock                basalt, scree, standing stone, crater rim
#   F  WALL   fence               a thin built barrier — pen rail, jetty edge, ore-cart rail
#   *  ANCH   prop-anchor         a data/nodes/*.json props[] entry, at floor(x/cellPx), floor(y/cellPx)
#   @  ANCH   spawn-anchor        documentary marker for the centre cell the spawn search starts from
#   ^  ANCH   edge-mouth          the cell where a corridor meets the map edge; one per declared adjacency
#   D  ANCH   door-anchor         the walkable cell a building is entered from
#
# Only "#"-class characters block. tools/mapgen/layout.ts normalises every WALL character to "#"
# before game/collision.ts gridFromAscii sees it; ANCH characters parse as floor and are read again
# on a second pass. Region kinds are open strings — add a row to the legend, not a case to a switch.
