# HAND-AUTHORED LAYOUT for "bowerdeep" — this file IS the map.
#
# It began as the seed tools/mapgen/seed.ts wrote and keeps that file's coordinate space,
# legend block and "---" separator. Everything below the separator was redrawn by hand:
# the composer stamps a tile per character, so painting and collision now come from THIS
# grid and cannot disagree. Re-running the seeder over it would throw the map away.
#
# ── coordinate space ─────────────────────────────────────────────────────────
# space        map-native pixels, origin TOP-LEFT (data/nodes/*.json props[].x/y are in this space)
# grid         64 cols × 64 rows, one character per collision cell
# cell         16 native px  (balance.map.collisionCellPx; 1024/64 = 16)
# map          1024 × 1024 native px, rendered ×2 → 2048 world px
# tiles        64 × 64 movement tiles of 32 world px
# col ← x      col = floor(nativeX / 16);  a cell's centre is native (16·col + 8, 16·row + 8)
# centre       native (512, 512) = cell (32, 32) = the tile firstWalkableTile starts on
#
# ── the node this is drawn from ──────────────────────────────────────────────
# biome        Forest
# adjacency    r2, r3
# bottom edge  r2   — ^ at (33,63); the litter track from the foot of the broad timber stair,
#                     barge landing on the Brackmarsh
# top edge     r3   — ^ at (20,0); the walk itself, carrying on into the Bowerdeep Wilds
# settlement   yes — FIVE buildings, every one of them named by the shipped subject line
#                    (tools/comfy/manifest.json _nodes.bowerdeep.feature)
# props        bowerdeep-sign-market @ (520,560) → cell (32,35), ON its authored cell
#
# ── decisions this file made ─────────────────────────────────────────────────
# · THIS MAP WAS REDESIGNED. It and brackwater were the same picture — one ribbon crossing the
#   frame between near-identical mouth columns, five buildings pinned to it alternating side to
#   side, everything else solid, differing only in whether the mass was water or canopy. That is
#   the owner's quoted rejection reproduced. bowerdeep is the half that moved, because
#   brackwater's topology is forced by its own subject line ("plank decking ... the only thing
#   anywhere that can be walked on"), because brackwater is one of the two highest-traffic maps,
#   and because bowerdeep's subject line hands it a device brackwater cannot have: a SECOND
#   LEVEL, with a forest floor that is walkable ground.
# · FIGURE AND GROUND ARE FLIPPED. The leaf-litter floor is a broad walkable plane and is the
#   larger half of the walkable map; the plank walk is a raised structure ON it, reached only by
#   the two stairs the subject line names. brackwater reads "the ribbon is the only way across";
#   bowerdeep reads "the ribbon is a place above the way across".
# · THE HANDRAIL IS COLLISION. Every board that faces the litter is fenced ("F"). The rail opens
#   in exactly three places: the top mouth, the foot of the broad timber stair, and the foot of
#   the east stair. That is what makes the walk read as a walk rather than as a wide dirt path.
# · THE BUILDINGS ARE NOT BEADS ON A STRING. Three cluster round the market square at the head
#   of the walk; the gym and the inn stand far south on their own widenings.
#     night-market stalls (22,1)-(28,7)    7x7 door (25,8)
#     oil shed            (41,2)-(46,7)    6x6 door (43,8)   the smallest, behind the house
#     winding house       (33,5)-(38,12)   6x8 door (36,13)  tall and narrow
#     gym hall            (34,37)-(41,44)  8x8 door (37,45)  the largest
#     inn                 (47,44)-(54,50)  8x7 door (50,51)
# · THE MOUTHS ARE ON THE OTHER DIAGONAL FROM BRACKWATER'S: bottom col 33 (= r2's top mouth) to
#   top col 20 (= r3's bottom mouth). Right to left going up, where brackwater runs left to right.
# · THE PROP IS ON ITS AUTHORED CELL (32,35) and data/nodes/bowerdeep.json needs no edit. It is
#   exactly three cells from the arrival tile — the edge of the clearance ring, not inside it —
#   and it is a walkable anchor, not a built thing. Recorded rather than resolved by moving it.
# · THE LITTER TRACK wanders the forest floor for two screens before it reaches the broad stair,
#   so the first thing a player walking up from the Brackmarsh sees is forest, not boards.
#
# ── legend (tools/mapgen/legend.ts) ──────────────────────────────────────────
#   .  floor  open-ground         plain walkable ground; the default fill
#   ,  floor  scrub               walkable but textured — long grass, ferns, heather
#   :  floor  path-corridor       the worn track that joins the map edges through the middle
#   o  floor  centre-clearing     the open region at native (512,512) the spawn search lands in
#   ~  floor  shallow             walkable water margin — wadeable, not a wall
#   #  WALL   wall                generic impassable mass with no more specific kind
#   B  WALL   building-footprint  a building the player walks around, never through
#   T  WALL   tree-mass           trunks and thicket dense enough to stop a walk
#   W  WALL   water               open water — deep enough to block
#   R  WALL   rock                basalt, scree, standing stone, crater rim
#   F  WALL   fence               a thin built barrier — pen rail, jetty edge, ore-cart rail
#   *  ANCH   prop-anchor         a data/nodes/*.json props[] entry, at floor(x/cellPx), floor(y/cellPx)
#   @  ANCH   spawn-anchor        documentary marker for the centre cell the spawn search starts from
#   ^  ANCH   edge-mouth          the cell where a corridor meets the map edge; one per declared adjacency
#   D  ANCH   door-anchor         the walkable cell a building is entered from
#
# Only "#"-class characters block. tools/mapgen/layout.ts normalises every WALL character to "#"
# before game/collision.ts gridFromAscii sees it; ANCH characters parse as floor and are read again
# on a second pass. Region kinds are open strings — add a row to the legend, not a case to a switch.
