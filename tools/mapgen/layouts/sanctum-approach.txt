# HAND-AUTHORED LAYOUT for "sanctum-approach" — the Sanctum Approach. THIS FILE IS THE MAP.
#
# Redesigned from the layout tools/mapgen/seed.ts wrote. The maps are composed from TILES now,
# stamped cell by cell from this grid, so the painting and the collision mask correspond by
# construction: every flight of the stair, every retaining wall and every drift of ash is exactly
# where it is written here. A boring grid here is a boring map; no tile can save it. Re-running the
# seeder with --force OVERWRITES this file; the renderers read this file, never the seeder.
#
# ── coordinate space ─────────────────────────────────────────────────────────
# space        map-native pixels, origin TOP-LEFT (data/nodes/*.json props[].x/y are in this space)
# grid         64 cols × 64 rows, one character per collision cell
# cell         16 native px  (balance.map.collisionCellPx; 1024/64 = 16)
# map          1024 × 1024 native px, rendered ×2 → 2048 world px
# tiles        64 × 64 movement tiles of 32 world px
# col ← x      col = floor(nativeX / 16);  a cell's centre is native (16·col + 8, 16·row + 8)
# centre       native (512, 512) = cell (32, 32) = the tile firstWalkableTile starts on
#
# ── seeded from ──────────────────────────────────────────────────────────────
# biome        Sanctum
# adjacency    r5, sanctum
# bottom edge  r5            — ^ at (40,63), on r5's top mouth; the stair drops to the vale
# top edge     sanctum       — ^ at (20,0), on the sanctum's gate; the dark cleft
# settlement   no — zero building footprints
# props        sanctum-approach-antler-gate @ (512,760) → cell (32,47)
#              sanctum-approach-antler-inner @ (512,372) → cell (32,23)
#
# ── what this place is (tools/comfy/manifest.json _nodes["sanctum-approach"], followed) ───────
# Mostly grey ash and bare rock: ONE LONG ASCENT UP THE FLANK OF A CRATER, drifted grey ash over
# cracked stone, low cut-rock retaining walls, scree fans and fallen blocks none of them bigger
# than a crate, NO PLANTS ANYWHERE. So this layout spells the whole map with five characters —
# '.' bare ash, ',' deep drift, ':' the stair, 'o' the landing, 'R' rock — and carries no 'T',
# no 'W', no '~', no 'F' and no 'B'. It is the only node in the region with no green on it.
#
# THE STAIR. A single WIDE stone stair climbs the whole height of the picture in long switchbacks:
# five flights and four hairpins, bottom to top, and it is the only path on the map.
#   · rows 59–63, cols 28–32   the stair drops away at the bottom toward the vale (the r5 mouth)
#   · rows 55–59, cols 28–50   leg A, east — FIVE cells deep, the broadest flight, lowest down
#   · rows 48–51, cols 20–50   leg B, west — the long one; the gate stone stands beside it
#   · rows 41–44, cols 20–40   leg C, east
#   · rows 34–37, cols 28–40   the traverse across the landing, west
#   · rows 24–37, cols 28–31   the run north, straight across the middle of the landing
#   · rows 21–24, cols 13–31   leg D, west
#   · rows  9–24, cols 13–16   the long flight against the west wall — sixteen rows, no turn
#   · rows  9–12, cols 13–34   leg E, east
#   · rows  5– 7, cols 19–34   leg F, west — THREE cells deep; the stair has narrowed
#   · rows  0– 7, cols 19–21   the dark cleft in the crater wall (the sanctum mouth)
# The flights are not evenly spaced and not the same length or the same width: the stair is broad
# and heavy where it leaves the vale and narrow where it enters the rock, and the two vertical
# flights (rows 24–37 and rows 9–24) are what stop the switchback reading as a ladder.
#
# THE LANDING. An open level landing of bare ash at the exact middle, rows 25–39, cols 23–44, an
# irregular oval of 'o' that the stair crosses without turning. Cell (32,32) is on it, one step
# east of the stair, and the whole landing is free of rock, prop and drift.
#
# THE TWO STONES, at their authored pixels, both beside the stair and neither beside the other.
#   · sanctum-approach-antler-gate, cell (32,47) — on the centre line well below the middle, in the
#     ash shoulder between leg B and the cut-rock face at row 46 the stone is SET INTO.
#   · sanctum-approach-antler-inner, cell (32,23) — above the middle on the same line, east of the
#     turn at the head of leg D, against the cut rock at cols 33–35 rows 19–27.
#
# ── decisions this file made ─────────────────────────────────────────────────
# · THIS NODE IS A ROUTE, NOT A TOWN, and carries zero buildings. tools/comfy/manifest.json gives
#   it kind "route", docs/content-bible.md §6 counts it among the six routes, tools/mapgen/nodes.ts
#   derives settlement=false, and checkSettlementOnly fails any footprint here. A round brief that
#   asked for four to seven buildings on this node was wrong about the node, and drawing them would
#   have been inventing content (G2) and turning the shipped suite red.
# · THE LANDING IS RE-CUT AS A TERRACE, NOT A DISC. "An open level landing of bare ash at the exact
#   middle" is authored, but it was drawn as a near-circular pale lozenge centred on (32,32) — the
#   same module six of the twelve nodes were painting on the one cell the player sees on every
#   entry to every node. It is now a level shelf much wider than it is deep, with a ragged uphill
#   edge, which is what a shelf on a switchback actually is.
# · THE LOW CUT-ROCK RETAINING WALLS the subject line names are drawn, in "F", hard against the
#   downhill edge of each flight. They are the frame material nothing else in the region has, and
#   they are what stopped every edge being a uniform band of one character.
# · THE BOTTOM MOUTH MOVED TO COL 40 to sit on r5's top mouth; the seam used to snap ten columns.
# · ENCOUNTER TERRAIN at 23.5% — the route figure, not the "little or none" a town gets. This node
#   carries a real population (carricrow-line) and balance.json's encounterTileFraction is 0.25.
#
# ── legend (tools/mapgen/legend.ts) ──────────────────────────────────────────
#   .  floor  open-ground         plain walkable ground; the default fill
#   ,  floor  scrub               walkable but textured — long grass, ferns, heather
#   :  floor  path-corridor       the worn track that joins the map edges through the middle
#   o  floor  centre-clearing     the open region at native (512,512) the spawn search lands in
#   ~  floor  shallow             walkable water margin — wadeable, not a wall
#   #  WALL   wall                generic impassable mass with no more specific kind
#   B  WALL   building-footprint  a building the player walks around, never through
#   T  WALL   tree-mass           trunks and thicket dense enough to stop a walk
#   W  WALL   water               open water — deep enough to block
#   R  WALL   rock                basalt, scree, standing stone, crater rim
#   F  WALL   fence               a thin built barrier — pen rail, jetty edge, ore-cart rail
#   *  ANCH   prop-anchor         a data/nodes/*.json props[] entry, at floor(x/cellPx), floor(y/cellPx)
#   @  ANCH   spawn-anchor        documentary marker for the centre cell the spawn search starts from
#   ^  ANCH   edge-mouth          the cell where a corridor meets the map edge; one per declared adjacency
#   D  ANCH   door-anchor         the walkable cell a building is entered from
#
# Only "#"-class characters block. tools/mapgen/layout.ts normalises every WALL character to "#"
# before game/collision.ts gridFromAscii sees it; ANCH characters parse as floor and are read again
# on a second pass. Region kinds are open strings — add a row to the legend, not a case to a switch.
