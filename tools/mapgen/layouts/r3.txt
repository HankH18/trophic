# LAYOUT for "r3" — Bowerdeep Wilds. Hand-authored. THIS FILE IS THE MAP DESIGN.
#
# The composer stamps one tile per character, so the painting and the collision both come
# out of this grid and cannot disagree about a wall. Every trunk, every patch of fern, the
# trail, the cut ground and the stone are placed below, cell by cell, on purpose.
#
# ── coordinate space ─────────────────────────────────────────────────────────
# space        map-native pixels, origin TOP-LEFT (data/nodes/*.json props[].x/y are in this space)
# grid         64 cols × 64 rows, one character per collision cell
# cell         16 native px  (balance.map.collisionCellPx; 1024/64 = 16)
# map          1024 × 1024 native px, rendered ×2 → 2048 world px
# tiles        64 × 64 movement tiles of 32 world px
# col ← x      col = floor(nativeX / 16);  a cell's centre is native (16·col + 8, 16·row + 8)
# centre       native (512, 512) = cell (32, 32) = the tile firstWalkableTile starts on
# screen       the player sees 15 × 10 cells at once
#
# ── authored from ────────────────────────────────────────────────────────────
# biome        Forest
# adjacency    bowerdeep, cindershelf
# bottom edge  bowerdeep — down toward the canopy town.  ONE mouth, ^ at (20,63), on bowerdeep's top mouth
# top edge     cindershelf — up onto bare stone toward the ash country.  ONE mouth, ^ at (22,0), on cindershelf's bottom mouth
# settlement   no — zero building footprints, zero doors; this is a route
# props        r3-antler-canopy @ native (430,336) → cell (26,21), placed where the JSON puts it
# subject      tools/comfy/manifest.json _nodes.r3: dark forest floor under closely spaced
#              slender trunks; one narrow trodden trail from the foot of the picture to the
#              top, doubling back on itself twice where the ground steepens; a small felled
#              clearing well above and right of the middle with fresh stumps and one stack of
#              cut logs set back off the trail; the trail bare dirt with nothing on it at the
#              exact middle; a granite stone wedged between two trunks above and left of it.
#
# ── decisions this file made ─────────────────────────────────────────────────
# · THE PLACE. A forest slope climbed by one narrow trodden trail that doubles back twice, each
#   hairpin wrapping a rock nose so the reversal has a reason on the ground. The felled clearing
#   sits well above and right of the middle, set back off the trail; the antler stone is wedged
#   between two trunks above and left of it. Both are reached across the forest floor — there is
#   deliberately no spur to either, because a spur on a route can only end in open ground.
# · THE TOP THIRD WAS REBUILT. It was a one-cell dither of alternating rock and trunk — the
#   "confetti" texture four routes shared, and the single most template-looking thing in the set.
#   It is now trunk CLUMPS of five different shapes on a jittered lattice with real floor between
#   them, under one stony apron with a lobed lower edge where the ground goes bare toward the
#   ash country.
# · 92 MAROONED CELLS ARE GONE. Ninety-two single walkable cells were sealed inside the canopy,
#   unreachable from the arrival tile; each would have stamped one bare-ground tile inside a solid
#   wood. Every walkable cell on this map is now reachable from (32,32).
# · THE TOP MOUTH MOVED TO COL 22, to sit on cindershelf's bottom mouth; the seam used to snap
#   seventeen columns sideways.
#
# ── legend (tools/mapgen/legend.ts) ──────────────────────────────────────────
#   .  floor  open-ground         plain walkable ground; the default fill
#   ,  floor  scrub               walkable but textured — long grass, ferns, heather
#   :  floor  path-corridor       the worn track that joins the map edges through the middle
#   o  floor  centre-clearing     the open region at native (512,512) the spawn search lands in
#   ~  floor  shallow             walkable water margin — wadeable, not a wall
#   #  WALL   wall                generic impassable mass with no more specific kind
#   B  WALL   building-footprint  a building the player walks around, never through
#   T  WALL   tree-mass           trunks and thicket dense enough to stop a walk
#   W  WALL   water               open water — deep enough to block
#   R  WALL   rock                basalt, scree, standing stone, crater rim
#   F  WALL   fence               a thin built barrier — pen rail, jetty edge, ore-cart rail
#   *  ANCH   prop-anchor         a data/nodes/*.json props[] entry, at floor(x/cellPx), floor(y/cellPx)
#   @  ANCH   spawn-anchor        documentary marker for the centre cell the spawn search starts from
#   ^  ANCH   edge-mouth          the cell where a corridor meets the map edge; one per declared adjacency
#   D  ANCH   door-anchor         the walkable cell a building is entered from
#
# This file uses 'o' for the felled clearing's cut ground rather than for the map centre: the
# subject line says the middle is trodden trail with nothing on it, and a clearing is what 'o'
# means. The legend has no stump character and no log-stack character, so the stumps are drawn
# with the tree-mass char 'T' as single isolated cells and the log stack with 'F', the timber
# barrier; 'R' carries the crags and the short flat bars of bare rock lying across the slope
# where the ground steepens. The blaze marks on the standing trunks have no character at all —
# that is a tile-level mark, recorded as open in _notes-r3.md rather than invented here.
#
# Only "#"-class characters block. tools/mapgen/layout.ts normalises every WALL character to "#"
# before game/collision.ts gridFromAscii sees it; ANCH characters parse as floor and are read again
# on a second pass. Region kinds are open strings — add a row to the legend, not a case to a switch.
