# HAND-AUTHORED LAYOUT for "r1" — Meadow Reach. THE LAYOUT IS THE MAP DESIGN.
#
# Seeded by tools/mapgen/seed.ts, then redesigned cell by cell. The maps are composed from
# tiles now, stamped from this grid, so painting and collision correspond BY CONSTRUCTION and
# this file is the map: every thicket, every stone, every patch of tussock is exactly where it
# is written here. Re-running the seeder OVERWRITES this; the renderers read this file.
#
# ── coordinate space ─────────────────────────────────────────────────────────
# space        map-native pixels, origin TOP-LEFT (data/nodes/*.json props[].x/y are in this space)
# grid         64 cols × 64 rows, one character per collision cell
# cell         16 native px  (balance.map.collisionCellPx; 1024/64 = 16)
# map          1024 × 1024 native px, rendered ×2 → 2048 world px
# tiles        64 × 64 movement tiles of 32 world px
# col ← x      col = floor(nativeX / 16);  a cell's centre is native (16·col + 8, 16·row + 8)
# centre       native (512, 512) = cell (32, 32) = the tile firstWalkableTile starts on
# screen       the player sees 240×160 native = 15 × 10 CELLS at a time
#
# ── seeded from ──────────────────────────────────────────────────────────────
# biome        Meadow
# adjacency    hearthollow, brackwater
# bottom edge  hearthollow — ^ at (41,63), on hearthollow's field gate; the gate gap in the wall
# top edge     brackwater — ^ at (26,0), on brackwater's bottom mouth; the marsh begins here
# settlement   no — zero building footprints, zero doors
# props        r1-antler-north @ (316,244) → cell (19,15); r1-antler-south @ (742,690) → cell (46,43); r1-sign-forage @ (480,470) → cell (30,29), on its authored cell
# subject      tools/comfy/manifest.json _nodes.r1 — "mostly deep grass … one thin worn dirt
#              track wanders up the picture, swinging wide round each thicket and crossing a
#              shallow stream on planks … bare earth at the exact middle … a gate gap in a
#              broken drystone wall toward the village … No fences, no square fields"
#
# ── decisions this file made ─────────────────────────────────────────────────
# · THE PLACE. A meadow that steps up as it climbs: a broken drystone wall along the foot
#   with the gate gap the track leaves by, a blocking stream crossed on planks with one other
#   ford, a bar of bare rock across the middle, and — new in this pass — a MARSH ONSET across
#   the top: standing water with wadeable margins and reed, so the walk on into brackwater's
#   open-water field has an approach on this side instead of cutting straight from dry meadow
#   to 80% water. The subject line's own words are "goes on at the top toward the marsh".
# · THE MOUTHS SIT ON THEIR NEIGHBOURS. Top mouth col 26 = brackwater's bottom mouth col 26;
#   bottom mouth col 41 = hearthollow's top mouth col 41. The top mouth moved from col 22.
# · NO PALE DISC AT THE ARRIVAL TILE. The centre-clearing lozenge this map used to paint on
#   (32,32) is gone — it was on six of the twelve nodes and was the closest thing in the set
#   to a repeated module, on the one cell the player sees on every entry to every node. The
#   middle is worn bare earth, which is what the subject line asks for.
# · THE PROP SITS ON ITS AUTHORED CELL. r1-sign-forage is at (30,29) = floor(480/16),
#   floor(470/16). data/nodes/r1.json is unchanged.
# · ENCOUNTER TERRAIN. 24.1% of walkable in large connected fields either side of the track,
#   none of it on the track, so the map can be crossed mouth to mouth without a forced roll.
#
# ── legend (tools/mapgen/legend.ts) ──────────────────────────────────────────
#   .  floor  open-ground         plain walkable ground; the default fill
#   ,  floor  scrub               walkable but textured — long grass, ferns, heather
#   :  floor  path-corridor       the worn track that joins the map edges through the middle
#   o  floor  centre-clearing     the open region at native (512,512) the spawn search lands in
#   ~  floor  shallow             walkable water margin — wadeable, not a wall
#   #  WALL   wall                generic impassable mass with no more specific kind
#   B  WALL   building-footprint  a building the player walks around, never through
#   T  WALL   tree-mass           trunks and thicket dense enough to stop a walk
#   W  WALL   water               open water — deep enough to block
#   R  WALL   rock                basalt, scree, standing stone, crater rim
#   F  WALL   fence               a thin built barrier — pen rail, jetty edge, ore-cart rail
#   *  ANCH   prop-anchor         a data/nodes/*.json props[] entry, at floor(x/cellPx), floor(y/cellPx)
#   @  ANCH   spawn-anchor        documentary marker for the centre cell the spawn search starts from
#   ^  ANCH   edge-mouth          the cell where a corridor meets the map edge; one per declared adjacency
#   D  ANCH   door-anchor         the walkable cell a building is entered from
#
# Only "#"-class characters block. tools/mapgen/layout.ts normalises every WALL character to "#"
# before game/collision.ts gridFromAscii sees it; ANCH characters parse as floor and are read again
# on a second pass. Region kinds are open strings — add a row to the legend, not a case to a switch.
