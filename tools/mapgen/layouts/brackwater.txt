# HAND-AUTHORED LAYOUT for "brackwater". This file IS the map design, not a collision spec.
#
# Every building, every plank, every reed bed is placed here and the composer stamps a tile
# per cell, so the painting and the collision correspond by construction. Re-running
# tools/mapgen/seed.ts OVERWRITES this by hand-edit; the renderers read this file, not the
# seeder. Content is authored -- tools/comfy/manifest.json _nodes.brackwater is the subject
# line every building below comes from, and nothing here was invented (G2).
#
# ── coordinate space ─────────────────────────────────────────────────────────
# space        map-native pixels, origin TOP-LEFT (data/nodes/*.json props[].x/y are in this space)
# grid         64 cols × 64 rows, one character per collision cell
# cell         16 native px  (balance.map.collisionCellPx; 1024/64 = 16)
# map          1024 × 1024 native px, rendered ×2 → 2048 world px
# tiles        64 × 64 movement tiles of 32 world px
# col ← x      col = floor(nativeX / 16);  a cell's centre is native (16·col + 8, 16·row + 8)
# centre       native (512, 512) = cell (32, 32) = the tile firstWalkableTile starts on
#
#
# ── authored from ────────────────────────────────────────────────────────────
# biome        Marsh
# adjacency    r1, r2
# bottom edge  r1 (the Meadow Reach, back toward Hearthollow) -- mouth at cell (26,63), on r1's gate gap
# top edge     r2 (the Brackmarsh, on toward the Sanctum)     -- mouth at cell (38,0), on r2's jetty
# settlement   yes -- a stilt town; NOTHING stands on dry land
# props        brackwater-idol-dock @ (388,726) -> cell (24,45), unmoved
# subject      manifest _nodes.brackwater.feature: dark brackish water over the whole
#              picture running off all four sides; five tarred timber buildings on plank
#              decks out over it; one open ferry landing; ONE crooked boardwalk in short
#              dog-legs with a short spur to each deck; wide empty decking at the exact
#              middle; a sunken idol below and left of the middle; stone steps up onto a
#              short low harbour wall low in the picture.
#
# ── decisions this file made ─────────────────────────────────────────────────
# · THE PLACE IS UNCHANGED and is the node whose topology its own subject line forces: brackish
#   water over the whole picture, and plank decking laid over it the only thing that can be
#   walked on. That is why brackwater is NOT the half of the brackwater/bowerdeep pair that
#   moved — it cannot stop being a ribbon with buildings hung off it without contradicting the
#   line it is drawn from. bowerdeep was redesigned instead.
# · THE FIVE FOOTPRINTS WERE RE-CUT. All five were outside the shipped 85-140px band and the
#   inn was not a solid rectangle, so tools/mapgen/verify.ts rejected the file. Now five
#   different rectangles, all in band, every door on the south face onto open deck:
#     angler's hut   (30,9)-(35,14)   6x6 = 96x96    door (33,15)   the smallest
#     supply shop    (41,41)-(46,47)  6x7 = 96x112   door (44,48)
#     fishery shed   (15,39)-(22,44)  8x6 = 128x96   door (18,45)   long and low
#     inn            (16,27)-(22,34)  7x8 = 112x128  door (19,35)   deep
#     gym hall       (48,24)-(55,31)  8x8 = 128x128  door (51,32)   the largest
# · TWO PLANK RUNS THAT STOPPED ON A REED FLAT are gone. The wadeable reed flats are kept but
#   now hang directly off the edge of a deck rather than at the end of a spur — a spur to a
#   reed flat is a path that stops in open ground, which is the defect this round exists to
#   remove. data/nodes/brackwater.json ships five populations here, so the flats earn a place.
# · THE MOUTHS SIT ON THEIR NEIGHBOURS: top col 38 = r2's jetty, bottom col 26 = r1's gate gap.
#
# ── legend (tools/mapgen/legend.ts) ──────────────────────────────────────────
#   .  floor  open-ground         plain walkable ground; the default fill
#   ,  floor  scrub               walkable but textured — long grass, ferns, heather
#   :  floor  path-corridor       the worn track that joins the map edges through the middle
#   o  floor  centre-clearing     the open region at native (512,512) the spawn search lands in
#   ~  floor  shallow             walkable water margin — wadeable, not a wall
#   #  WALL   wall                generic impassable mass with no more specific kind
#   B  WALL   building-footprint  a building the player walks around, never through
#   T  WALL   tree-mass           trunks and thicket dense enough to stop a walk
#   W  WALL   water               open water — deep enough to block
#   R  WALL   rock                basalt, scree, standing stone, crater rim
#   F  WALL   fence               a thin built barrier — pen rail, jetty edge, ore-cart rail
#   *  ANCH   prop-anchor         a data/nodes/*.json props[] entry, at floor(x/cellPx), floor(y/cellPx)
#   @  ANCH   spawn-anchor        documentary marker for the centre cell the spawn search starts from
#   ^  ANCH   edge-mouth          the cell where a corridor meets the map edge; one per declared adjacency
#   D  ANCH   door-anchor         the walkable cell a building is entered from
#
# Only "#"-class characters block. tools/mapgen/layout.ts normalises every WALL character to "#"
# before game/collision.ts gridFromAscii sees it; ANCH characters parse as floor and are read again
# on a second pass. Region kinds are open strings — add a row to the legend, not a case to a switch.
