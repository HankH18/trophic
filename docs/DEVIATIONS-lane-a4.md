# DEVIATIONS — Lane A4 (`core/lifecycle.ts`, `core/save.ts`)

Staged separately because `docs/DEVIATIONS.md` is held by lane A1 concurrently.
**Merge into `docs/DEVIATIONS.md` at integration** — build-doc's Audience note requires every
departure from the spec to be logged there, never silently.

Spec refs: build-doc §7.5 (party/aging/retirement), §7.8 (save), §8.1 (determinism), §4 (year-turn
triggers), bible §4 (species/ages), §9 (Cullbrand raids), §12 (creature card).

## Notes for other lanes

- **C6 (year-turn UX).** `advanceYear` never throws on a decision it cannot apply: it substitutes the
  rolled HEIR, reports it in `result.rejected` and emits a `choiceRejected` event. Grey the BOON
  button out when `boonTargetUids(save, balance, stat)` is empty — with a party caught together in
  year 1 this is the common case, not an edge case. Check `canRunYearTurn(save)` before firing the
  turn (§4's dual trigger), and watch `result.partyEmpty` / the `partyEmpty` event.
- **C4 (summary card).** `retiresBeyondFinalYear` (D-A4-14), and the `formChanged` event announces
  every identity change, including the A→E one (Vulkindle → Pyrevane) that only `metamorphosed`
  used to cover.
- **A5 (harness).** D-A4-9 and D-A4-10 are the two numbers to prove out; both are balance.json knobs.
- **C1 (boot/save).** Reload is `readSlot` + `openStreams`, never `replay(midRunSave, its own log)` —
  which now refuses rather than double-applying the ledger deltas.
