`game/year-replay.ts`, `game/scenes/YearTurnScene.ts`, `game/scenes/RetirementScene.ts`,

**Repair pass.** Rows C56-D2, C56-D3 and C56-D10 were CORRECTED after an independent verifier

the repairs that followed.

## Blockers reported out of this lane

1. **No `seasonTint` group in balance.json.** The four season hues are `PROVISIONAL_SEASON_TINTS` in
   `game/season-tint.ts`, flagged `provisional: true` and said so on screen. `zBalance` is a plain
   `z.object` and strips undeclared keys, so adding the group to the file alone would be a decoy no
   reader ever sees; it needs data/balance.json + `Balance` + `zBalance` in one change. The
   *magnitudes* (`audio.seasonBrightness`, `audio.yearDarkenPerYear`) are already data and are read.
2. **No `lifecycle` subsystem RNG tag** (C56-D10).
3. **`core/save.ts` `replay` models no clock.** Travel, foray and inn move no tick on the replay
   path, so a replayed save's `tick` is whatever the last `runYearTurn` set. `game/year-replay.ts`
   `withClockFromLog` reconstructs it from the log entries' own `{year, tick}`, which closes it for
   any caller that asks — but `replay()` itself still returns a save whose meter is fiction.
4. **`core/save.ts` `replay` takes one `rng` for a whole log.** It cannot key a heir roll to the
   prompt it belongs to, so "replay draws the same values in the same order" is only true while the
   live flow draws exactly once per LOGGED prompt. This lane holds that invariant on the scene path
   (a prompt neither side can answer is skipped before anything is rolled) and cannot hold it for a
   headless caller that hands `choose()` an illegal boon while a legal one exists.
5. **No `no_magic_numbers` gate over `game/`** (C56-D8). The four named gates in
   `tests/gates/guardrails.test.ts` are scoped to `core/`, so nothing in the tree would have caught
   the two literal viewport sizes. Extending the gate touches a shared gate file.
6. **The starter's schedule does not match bible §4** (C56-D11 / D-A4-9). A year-1 starter's final
   form arrives in year 3 and it retires entering year 4, where the bible says it "peaks right
   before the league, then retires" in year 6. Fixing it is a `balance.age` retune (data/balance.json
   + the A5 harness), which no file in this lane may touch.
7. **A new game seeds an empty party.** `startNewGame` takes an optional `party` and boot does not
   invent one (correctly — G2; build-doc §15 C7 owns the opening beat). Until C7 hands a starter
   over, a year turn reached by playing has nothing to age and nothing to retire, so the Legacy beat
   is *wired and reachable* but has no subject in a fresh run.
